Physical AI: จากศูนย์สู่ Microduck

เรียนว่า AI ควบคุมร่างกายในโลกจริงได้อย่างไร ตั้งแต่ coordinate, MuJoCo และ PD control ไปจนถึง Reinforcement Learning ที่ train ให้ bipedal robot Microduck เดิน ทุกตอนมีวิดีโอทฤษฎีแบบ animation, lab ที่เขียนโค้ดทีละบรรทัดใน Jupyter, วิดีโอสรุป และ notebook ที่เปิดใน Google Colab ได้ทันที

ทุกคลิปมีเสียงและ subtitle ไทยและอังกฤษ (EP01 เสียงไทยกำลังตามมา) · notebook ทุก lab มีฉบับภาษาอังกฤษ

เส้นทางการเรียน

เรียงตาม class ของวิชา ตอนที่ยังไม่เปิดจะทยอยออกทาง playlist

S1 ร่างกาย หุ่นรู้ได้อย่างไรว่าตัวเองอยู่ตรงไหน และสั่งให้ขยับได้อย่างไร

EP01

Physical AI คืออะไร พร้อมเรียน sense, think, act · ขับ Microduck ใน simulator

EP02

coordinate และ rotation เร็วๆ นี้ frame · rotation matrix · forward kinematics

EP03

ร่างกายหุ่นยนต์และ MuJoCo เร็วๆ นี้ servo · IMU · control loop 50 Hz · MjModel/MjData

EP04

สร้างหุ่นยนต์ด้วย MJCF เร็วๆ นี้ kinematic tree · mass · friction · model ของ Microduck

EP05

PD control เร็วๆ นี้ feedback · gain · overshoot · ทำไมการยืนสองขาจึงยาก

S2 การเรียนรู้ ถ้าเขียนกฎเองไม่ไหว จะให้หุ่นเรียนจาก reward ได้อย่างไร

EP06

RL และ MDP เร็วๆ นี้ state · action · reward · return · Gymnasium

EP07

Value และ Q-learning เร็วๆ นี้ Bellman · TD · Q-learning บน FrozenLake

EP08

Neural network และ policy gradient เร็วๆ นี้ REINFORCE บน CartPole · variance

EP09

Actor-critic และ PPO เร็วๆ นี้ advantage · PPO-Clip · อ่านกราฟ training

S3 Microduck จะทำให้ Microduck เดินได้และเชื่อถือได้อย่างไร

EP10

Train ให้ Microduck เดิน เร็วๆ นี้ parallel simulation · mjlab · ประเมิน policy

EP11

ออกแบบ reward เร็วๆ นี้ shaping · reward hacking · ทำนายก่อนรัน

EP12

Sim-to-real เร็วๆ นี้ domain randomization · backlash · ทดสอบ robustness

EP13

Deployment เร็วๆ นี้ ONNX · observation contract · ทดสอบข้าม simulator

EP14

Safety และ ethics เมื่อ AI มีร่างกาย เร็วๆ นี้ ความเสี่ยงที่ simulation ตรวจไม่เจอ

สิ่งที่ต้องมี

🐍

Python พื้นฐาน — เขียน variable, function และ loop ได้ ไม่ต้องมีพื้นฐานหุ่นยนต์หรือ RL

🌐

Browser — เปิด notebook ใน Google Colab ได้เลย ไม่ต้องติดตั้งอะไรบนเครื่อง

🤖

ไม่ต้องมีหุ่นจริง — ทั้งวิชาเรียนผ่าน simulation lab ของ Microduck (EP10–EP13) ใช้ checkpoint ที่เตรียมไว้ จึงไม่ต้องมี GPU

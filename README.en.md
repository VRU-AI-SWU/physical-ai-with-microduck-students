Notebooks for the YouTube series *Physical AI with Microduck* (English and Thai audio and subtitles) of the course Introduction to Physical AI, from coordinates, MuJoCo, and PD control to reinforcement learning that trains the Microduck bipedal robot to walk. Every lab has an English notebook; the links below open them.

📖 **Read the lessons online:** https://vru-ai-swu.github.io/physical-ai-with-microduck-students/en/

Each lab with code has two files (a lab with no code, like EP01 Lab 1 in the browser, has one notebook):

- **✏️ Starter** (`.en.student.ipynb`) — most of the code is ready; watch the video and fill in only the `✏️ TODO`s. Each TODO gives the time in the video where that code is explained.
- **✅ Solution** (`.en.ipynb`) — the same code as in the video, ready to run; compare when you get stuck.

## Getting started

1. Click **Open in Colab** for the lab you want (or download the `.ipynb` and open it in Jupyter)
2. Run every cell from top to bottom; the first cell installs the packages the lab needs

The Microduck labs (EP10–EP13) train on a GPU; their notebooks use prepared checkpoints instead.
